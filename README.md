> Projeto final do curso de PHP, consolidando conceitos fundamentais da linguagem em uma aplicação prática de portfólio.

## 🚀 Stack
- PHP
- Laravel
- Blade
- MySQL
- Tailwind CSS
- Composer

## ✨ Funcionalidades
- CRUD completo com PHP e MySQL
- Templates dinâmicos com Blade
- Interface estilizada com Tailwind CSS
- Código limpo e organizado, pronto para portfólio

## 📦 Instalação
```bash
composer install
```

## ▶️ Uso
```bash
php artisan serve
```
